## v2.1.0 — 2026-11-11

First packaged public release of Cypher Heirs.

- Ranked market overview, priority queue, interactive candle inspector and pinned watchlist.
- Analysis studio with 16 level sources, four R/C entry types, editable weights and thresholds, live draft preview and per-chart score arithmetic.
- Browser-local preferences with rule export/import and an editable asset universe.
- Browser-based Pine analysis of completed Binance USDT perpetual candles.
- Square-cornered dark interface with responsive navigation and mobile chart sheets.
- Product README, linked guides, promotional capture and GitHub Releases badge.

The frozen Pine 11.4.0 entry core is preserved. Attention preferences are discretionary, not evidence of a profitable strategy. Fills, costs, funding and ongoing position management are not simulated.
